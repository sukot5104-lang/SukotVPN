# 🛡️ Sukot VPN — فیلترشکن سریع و رایگان اندروید

**Sukot VPN** یک کلاینت VPN متن‌باز برای اندروید است که با موتور قدرتمند **Xray** کار می‌کند و برای عبور از فیلترینگ طراحی شده است. یوتیوب، تلگرام، گوگل و تمام سایت‌های فیلترشده را باز کنید.

<p align="center">
  <b>🌐 https://github.com/sukot5104-lang/SukotVPN</b>
</p>

---

## ✨ امکانات

- ⚡ **موتور Xray** (نسخه v26.10.10) — هسته رسمی و به‌روز
- 🔗 **پشتیبانی از ۴ پروتکل**: `VMess` ،`VLESS` (با Reality) ،`Trojan` ،`Shadowsocks`
- 📡 **آزمون پینگ و «اتصال به سریع‌ترین سرور»** با یک لمس
- 🆓 **لیست کانفیگ‌های رایگان** — با یک دکمه از چند منبع عمومی دریافت می‌شود
- 📥 **ورود دستی کانفیگ**: چسباندن لینک / اسکن QR / لینک اشتراک (Subscription)
- 📤 **اشتراک‌گذاری کانفیگ** با کد QR
- 🇮🇷 **دور زدن سایت‌های ایرانی** — بانک‌ها و سایت‌های داخلی بدون تونل باز می‌شوند
- 🚫 مسدود کردن QUIC / تبلیغات / تورنت (اختیاری)
- 🌍 **دوزبانه**: فارسی و انگلیسی (رابط کاملاً راست‌چین)
- 🎨 تم تیره لوکس با انیمیشن‌های روان
- 📱 پشتیبانی از **اندروید ۷ به بالا** (API 24+) — arm64 / arm32 / x86

## 📲 دانلود و نصب

### راه ۱: آخرین بیلد خودکار (پیشنهادی)
1. به بخش [**Releases**](https://github.com/sukot5104-lang/SukotVPN/releases) بروید
2. آخرین نسخه را باز کنید و فایل `app-release.apk` را دانلود کنید

### راه ۲: از Actions
1. تب [**Actions**](https://github.com/sukot5104-lang/SukotVPN/actions) را باز کنید
2. آخرین بیلد موفق را انتخاب کنید
3. از بخش **Artifacts** فایل `SukotVPN-APK` را دانلود کنید

> ⚠️ هنگام نصب، پیام «منبع ناشناس» را تأیید کنید. هنگام اولین اتصال، اجازه VPN را بدهید.

## 🚀 استفاده

1. برنامه را باز کنید و **دریافت کانفیگ‌های رایگان** را بزنید (یا لینک کانفیگ خودتان را وارد کنید)
2. از تب «سرورها» یکی را انتخاب کنید یا دکمه **سریع‌ترین** را بزنید
3. دکمه بزرگ اتصال را لمس کنید — تمام! 🎉

## 🛠️ ساخت از سورس

```bash
git clone https://github.com/sukot5104-lang/SukotVPN.git
cd SukotVPN
./scripts/fetch-core.sh     # دانلود موتور Xray (~65MB)
./gradlew assembleRelease
```

نیازمندی‌ها: JDK 17 + Android SDK 35

## 🏗️ ساختار پروژه

```
app/src/main/java/com/sukot/vpn/
├── core/          ← پوشش موتور libv2ray (Xray)
├── service/       ← سرویس VPN (پروسه جداگانه daemon)
├── xray/          ← تولید کانفیگ JSON برای هسته
├── util/          ← پارسر لینک‌های vmess/vless/trojan/ss
├── data/          ← ذخیره‌سازی، دریافت کانفیگ، تست سرعت
├── model/         ← مدل سرور
└── ui/            ← رابط کاربری Jetpack Compose
```
