# راهنمای ریپوی SukotVPN

این ریپو به صورت خودکار APK فیلترشکن **Sukot VPN** را می‌سازد.

## 📲 دانلود APK

### از Releases (پیشنهادی)
1. به آدرس زیر بروید:
   `https://github.com/sukot5104-lang/SukotVPN/releases`
2. روی آخرین نسخه (مثلاً `build-3`) کلیک کنید
3. فایل `app-release.apk` را دانلود و نصب کنید

### از تب Actions
1. وارد تب **Actions** شوید
2. روی آخرین بیلد سبز (✅) کلیک کنید
3. در پایین صفحه از قسمت **Artifacts** فایل را دانلود کنید
4. فایل zip دانلودشده را باز کنید و APK را نصب کنید

## ⚙️ بیلد مجدد

هر بار که کدی push شود، GitHub Actions به صورت خودکار:
1. موتور Xray (libv2ray.aar) را دانلود می‌کند
2. JDK 17 را آماده می‌کند
3. APK release امضاشده می‌سازد
4. در **Artifacts** و **Releases** قرار می‌دهد

برای بیلد دستی: تب **Actions** → **Build Sukot VPN APK** → **Run workflow**

## 🔧 اگر بیلد شکست خورد

1. وارد بیلد قرمز (❌) شوید و لاگ مرحله‌ی شکست‌خورده را بررسی کنید
2. رایج‌ترین مشکل: قطع شدن دانلود AAR — دوباره **Run workflow** بزنید

## 📁 ساختار مهم

| مسیر | توضیح |
|------|-------|
| `.github/workflows/build.yml` | بیلد خودکار |
| `app/src/` | سورس کد برنامه |
| `scripts/fetch-core.sh` | دانلود موتور برای بیلد محلی |
| `gradle/libs.versions.toml` | نسخه‌ی کتابخانه‌ها |

## 🔐 نکته امضا

APKها با کلیدی که هنگام بیلد در CI ساخته می‌شود امضا می‌شوند. برای انتشار پایدار بهتر است یک keystore ثابت بسازید و به عنوان Secret به ریپو اضافه کنید.
